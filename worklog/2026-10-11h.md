## Root Cause

Backend `getDashboard` returned:
```typescript
{ asOf, todayRevenue, todayOrderCount, newPatientsToday, openConversations, pendingPrescriptions, lowStockCount }
```

Frontend `DashboardMetrics` expected:
```typescript
{ users: {...}, approvals: {...}, orders: {...}, products: {...}, revenue: {...}, charts: {...}, healthcare: {...} }
```

API returned 200 with mismatched data → `m` was truthy (object), `m.orders` was `undefined` → JS crash at `m.orders.byStatus` on line 156. The `if (isError || !m)` guard at line 140 did not catch it because `m` itself was not null/undefined.

### backend/src/modules/reports/reports.types.ts

Replaced the 7-field flat `DashboardResult` with the nested shape that matches `DashboardMetrics`:
```typescript
export interface DashboardResult {
  users:      { total: number; newToday: number };
  approvals:  { pendingClinics: number; pendingPartners: number };
  orders:     { total: number; today: number; pending: number; byStatus: Array<{ status: string; count: number }> };
  products:   { active: number; lowStock: number };
  revenue:    { totalCents: number; totalCAD: string };
  charts:     { dailyOrders: Array<{ date: string; count: number; revenue: number }> };
  healthcare: { pendingCompounding: number; openAskPharmacist: number; pendingAppointments: number; activePrescriptions: number };
}
```

### backend/src/modules/reports/reports.service.ts

Rewrote `getDashboard` with:
- `buildDashboardResult(...)` helper — pure data transform (no DB), takes raw query results and builds `DashboardResult`
- `runQueries(db: any)` — runs 12 parallel SQL queries, callable against both `superAdminDb` and `TenantTransaction`
- Super admin path: `runQueries(superAdminDb)` (platform-wide via BYPASSRLS)
- Facility path: `withTenantContext(facilityId, (tx) => runQueries(tx))` (RLS-enforced)

Queries run in parallel via `Promise.all`:
1. Patient total (role = 'patient')
2. Patients new today
3. Orders by status (GROUP BY status)
4. Orders today (created_at >= midnight UTC)
5. Active products (is_active = true)
6. Low stock products (COUNT DISTINCT product_id where quantity <= threshold)
7. Revenue all-time CAD (SUM of shipped/delivered orders)
8. Daily orders last 7 days (date, count, revenue — gaps filled in JS)
9. Pending compounding (status IN ('submitted', 'reviewing'))
10. Open ask-pharmacist (status = 'open')
11. Scheduled appointments (status = 'scheduled')
12. Active prescriptions (status IN ('submitted', 'under_review'))
