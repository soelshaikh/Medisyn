## Decisions Made This Session

| Decision | Status |
|---|---|
| Queue library: BullMQ v5 on existing ioredis | CONFIRMED |
| Template engine: Handlebars on-disk templates, memory-cached | CONFIRMED |
| Appointment reminder: BullMQ repeatable job (hourly scan, 24–25h window) | CONFIRMED |
| Unread count: Redis INCR/DECR cache (`notifications:unread:{uid}:{fid}`), 10-min TTL | CONFIRMED |
| email_log.facility_id: nullable (NULL for system/platform emails) | CONFIRMED |
| Notification inserts: synchronous within domain tx (not via separate queue job) | CONFIRMED |
| Redis unavailability: fall back to sync nodemailer send (never silent drop) | CONFIRMED |
| Worker architecture: co-process with Express in dev; splittable in prod | CONFIRMED |
