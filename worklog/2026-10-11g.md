# Session: 2026-10-11g — Phase 12 Backend Route Modules: Users, Roles, Permissions, Audit

## Summary
Built the 4 missing backend route modules required by the admin panel, fixed 2 admin API files, and wired everything into app.ts.

## Files Created

### Backend — new files
- `backend/src/core/super-admin/admin-users.service.ts`
  - `adminListUsers(facilityId, params)` — paginated list with filters: `status`, `search`, `hasRoles` (false=patients, true=staff)
  - `adminSearchUsers(facilityId, q)` — quick search (name/email), max 20 results
  - `adminGetUserById(facilityId, userId)` — single user detail
  - `adminSetUserStatus(actorId, facilityId, userId, status, ...)` — toggle `facilityUsers.isActive`; audit via `superAdminQuery`
  - `adminSetUserRoles(actorId, facilityId, userId, roleIds, ...)` — update `facilityUsers.roleId` (one role per user)
  - All DB access via `superAdminDb` (ESLint-enforced in `src/core/super-admin/`)

- `backend/src/core/super-admin/admin-roles.service.ts`
  - `adminListRoles(facilityId)` — roles + permission keys (array_agg with filter)
  - `adminGetRoleById(facilityId, roleId)` — role detail + permission keys
  - `adminCreateRole(actorId, facilityId, name, ...)` — insert; system roles not created via API
  - `adminUpdateRole(actorId, facilityId, roleId, name, ...)` — rejects system role rename
  - `adminDeleteRole(actorId, facilityId, roleId, ...)` — rejects system role delete
  - `adminSetRolePermissions(actorId, facilityId, roleId, permissionKeys, ...)` — resolves keys→IDs via `inArray`, replaces all permissions
  - `adminListPermissions()` — platform-wide `permissions` table; group derived from key prefix

- `backend/src/core/super-admin/admin-users.router.ts`
  - `GET  /users/search?q=...` → search (declared before `/:id` to prevent route shadowing)
  - `GET  /users` → paginated list
  - `GET  /users/:id` → detail
  - `PATCH /users/:id/status` → activate/suspend
  - `PATCH /users/:id/roles` → change role

- `backend/src/core/super-admin/admin-roles.router.ts`
  - `GET    /admin/roles`
  - `POST   /admin/roles`
  - `GET    /admin/roles/:id`
  - `PATCH  /admin/roles/:id`
  - `DELETE /admin/roles/:id`
  - `PUT    /admin/roles/:id/permissions`

- `backend/src/core/super-admin/admin-permissions.router.ts`
  - `GET /admin/permissions`

- `backend/src/core/super-admin/admin-audit.router.ts`
  - `GET /admin/audit` — paginated, sorted desc createdAt, left-joins `users` for `userEmail`
  - `bigserial id` → returned as string via `String(r.id)`
