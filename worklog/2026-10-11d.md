## Decisions Made

| Decision | Status |
|---|---|
| AWS SDK v3 (@aws-sdk/client-s3 + @aws-sdk/s3-request-presigner) — works for both S3 and Cloudflare R2 | CONFIRMED |
| multer with memoryStorage() — file held in Buffer, passed to S3 SDK; oversized files rejected at multer layer | CONFIRMED |
| Schema: add file_keys text[] alongside existing file_reference (deprecated, not dropped) | CONFIRMED |
| FileStorageService is a lazy-init singleton — constructor does NOT throw on missing AWS_S3_BUCKET; methods throw 503 at call time | CONFIRMED |
| File upload endpoints are patient-facing only for now (ownership check only); admin file upload requires RBAC Phase 2 | CONFIRMED |
| File key namespace: {facilityId}/{module}/{uuid}.{ext} — ext derived from MIME type, not original filename | CONFIRMED |
| Migration script at src/scripts/migrate-base64-files.ts uses workerDb (BYPASSRLS) — valid for cross-facility one-shot script | CONFIRMED |
| Audit entries: action format 'file.upload' and 'file.sign_url' — validated against /^[a-z_]+\.[a-z_]+$/ pattern ✓ | CONFIRMED |
