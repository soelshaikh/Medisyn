### `frontend/src/components/patient/PatientThreadPanel.tsx` *(new)*
**Decision: CONFIRMED** — Extracted as reusable component.

Props:
- `entityType: string` — e.g. `"order"`, `"prescription"`, `"ask_pharmacist"`
- `entityId: string` — MongoDB ObjectId of the entity
- `title?: string` — optional heading (default: `"Messages from Pharmacy"`)
- `className?: string` — for layout customization

Behaviour:
- `useQuery` with key `[entityType, "thread", entityId]`, 30s refetchInterval
- Admin/system messages left-aligned (grey bubble), patient messages right-aligned (brand blue)
- Auto-scrolls to bottom when new messages arrive (useEffect on `messages.length`)
- Textarea with Ctrl+Enter shortcut to send
- `useMutation` calls `patientThreadsApi.postEntityMessage(entityType, entityId, { body })`
- Empty state: "No messages yet. Send us a message below…"
