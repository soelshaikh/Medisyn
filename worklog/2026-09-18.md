## Phase 9 — File Storage (Completed)

### Backend — FileStorageService

**`backend/src/modules/files/file-storage.service.ts`**

`IFileStorageService` interface with `upload`, `delete`, `getSignedUrl`, `isPrivate` methods.

Two implementations:
- `LocalFileStorage` — saves to `uploads/` folder, key = `{folder}/{uuid}.ext` flattened to `{folder}_{uuid}.ext` on disk
- `S3FileStorage` — AWS SDK `PutObjectCommand`/`DeleteObjectCommand`/`GetObjectCommand` + `getSignedUrl` from `@aws-sdk/s3-request-presigner`
  - Private paths (`private/...`) → presigned URL on upload + 1-hour GET presigned URL on demand
  - Public paths → direct `S3_PUBLIC_URL/{key}` or standard S3 URL

Factory: `storageService` exported singleton, selected by `FILE_STORAGE_PROVIDER` env var.

Works with: AWS S3, Cloudflare R2, MinIO, Backblaze B2 (any S3-compatible endpoint via `S3_ENDPOINT`).

**`backend/src/modules/files/files.routes.ts`**

- `POST /api/v1/files/upload?type=product-image|document` — multer memoryStorage → storageService.upload
  - `product-image`: max 5MB, jpeg/png/webp, folder `products/` (public)
  - `document`: max 20MB, pdf/jpeg/png/webp, folder `private/documents/` (private → signed URL)
  - Returns `{ key, url }`
- `GET /api/v1/files/signed-url?key=...` — 1-hour presigned URL; passes http/https URLs through unchanged
- Both require `authenticate`

### Backend — Product Image Migration

- `products.routes.ts` — `multer.diskStorage` → `multer.memoryStorage`
- `products.controller.ts` — `addImage` calls `storageService.upload()` + stores returned `url`
- `products.service.ts` — removed `fs`/`path` imports; `removeProductImage` calls `storageService.delete()`

### Backend — Config

New optional env vars in `config/index.ts`: `S3_ENDPOINT`, `S3_REGION`, `S3_BUCKET`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY`, `S3_PUBLIC_URL`

`.env.example` updated with full Cloudflare R2 and AWS S3 configuration examples.

### Admin UI

**`admin/src/components/common/SecureDocumentLink.tsx`** — smart document link component:
