### 1. Invoice Module (Backend)

**New files:**
- `backend/src/modules/invoices/invoice.schema.ts` — IInvoice document with snapshots (customer name/email/phone, billing address, items, tax lines, totals all in cents), guestToken (sparse unique), voidedAt/voidedBy/voidReason
- `backend/src/modules/invoices/invoiceCounter.schema.ts` — atomic sequence counter by FY key (e.g. "E-26-27")
- `backend/src/modules/invoices/invoice.numbering.ts` — `financialYear()` (April–March, uses APP_TIMEZONE), `nextInvoiceNumber()` via MongoDB `$inc` upsert — format `MP-{E|A}-{YY}-{YY}-{00001}` (always 16 chars)
- `backend/src/modules/invoices/invoice.service.ts` — `createFromOrder` (idempotent, checks existing by orderId), `createAdhoc`, `voidInvoice`, `listAdminInvoices`, `getAdminInvoice`, `listMyInvoices`, `getMyInvoice`, `getByGuestToken`, `invoiceSummary`
- `backend/src/modules/invoices/invoice.template.ts` — `renderInvoiceHtml()` with full inline-CSS MediSyn-branded HTML, all user content HTML-escaped, void banner when voided
- `backend/src/lib/playwrightPdf.service.ts` — `htmlToPdf()` (singleton browser, lazy import, new page per request, A4 format), `closePdfBrowser()` for graceful shutdown
- `backend/src/modules/invoices/invoices.routes.ts` — patient routes (`/my`, `/my/:id`, `/my/:id/pdf`), guest route (`/guest/pdf?token=`), admin routes (list, get, adhoc create, void, PDF, reports summary)

**Modified:**
- `backend/src/modules/permissions/permissions.catalog.ts` — added `invoices.read`, `invoices.create`, `invoices.void`
- `backend/src/modules/orders/orders.service.ts` — fires `createFromOrder()` fire-and-forget when order reaches `delivered` status
- `backend/src/app.ts` — registered `/api/v1/invoices`
- `backend/package.json` — added `playwright-core`
- `backend/.env.example` — added `APP_TIMEZONE`, `INVOICE_GUEST_TOKEN_TTL_DAYS`
- `backend/src/config/index.ts` — added above two config keys

**Key design decisions:**
- All amounts snapshotted at issuance — never recalculated
- Guest orders get a 32-byte hex token (stored with TTL) for unauthenticated PDF access
- `createFromOrder` is idempotent (unique sparse index on orderId + pre-check)
- Voiding is admin-only with mandatory reason; invoice stays in DB for audit
