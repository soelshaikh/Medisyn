## Decisions Made This Session

| Decision | Status |
|---|---|
| Platform name is **Vtech-Med** (not MediSyn) — MediSyn is one facility (tenant) | CONFIRMED |
| Vtech-Med is a multi-tenant SaaS platform; pharmacies/clinics/health networks are facilities | CONFIRMED |
| PostgreSQL replaces MongoDB | CONFIRMED |
| Drizzle ORM | CONFIRMED |
| Shared DB, `facility_id` on every facility-scoped table | CONFIRMED |
| PostgreSQL RLS is primary DB-level tenant isolation; fails CLOSED | CONFIRMED |
| Two DB roles: `app_user` (RLS enforced), `app_super_admin` (BYPASSRLS) | CONFIRMED |
| Two connection pools, one per DB role | CONFIRMED |
| PgBouncer transaction mode + `set_config(..., true)` (transaction-local tenant context) | CONFIRMED |
| Super admin cross-facility access is audit-gated (write before execute) | CONFIRMED |
| `auth_version` integer on users table for JWT staleness detection | CONFIRMED |
| Redis 60s TTL cache for auth version checks; immediate Redis.del on suspension | CONFIRMED |
| API keys are separate from JWT human auth; full lifecycle defined | CONFIRMED |
| CORS is not authentication — explicitly stated | CONFIRMED |
| Patient identity is **facility-scoped** (no cross-facility patient linking) | CONFIRMED |
| `health_card_number` encrypted at application layer (AES-256-GCM) | CONFIRMED |
| `audit_log` is append-only (no UPDATE/DELETE permissions granted to app_user) | CONFIRMED |
| Plan entitlements are DB-driven (plan_entitlements + facility_entitlement_overrides tables) | CONFIRMED |
| Payment gateway is out of scope | CONFIRMED |
| No microservices, no separate DBs per tenant | CONFIRMED |
| Stack: Express + PostgreSQL + Drizzle + Redis + Next.js | CONFIRMED |

- R3: 60-second JWT stale window — accepted trade-off; immediate invalidation on suspension
